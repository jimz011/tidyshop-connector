# Notifications

Notifications are **off** until you turn them on. They only ever concern **family lists**: a
personal list only changes when you change it. TidyShop also never notifies you while it's open in
front of you, because you can already see the lists.

Everything below is under **menu → Settings → Notifications**. If this phone hasn't
[joined a family](family.md) yet, there's nothing to notify about.

## What to tell me about

| Option | You're notified about |
| --- | --- |
| **Off** | Nothing. The default. |
| **Nudges only** | Only when a family member taps [Notify family](sharing.md#notify-family). |
| **Everything** | New items on family lists, and Notify family taps. |

On Android 13 and newer, Android asks for permission the first time. If notifications are blocked
there, TidyShop says so and offers **Open Android settings**.

## How many notifications

| Option | Looks like |
| --- | --- |
| **One per list** | *"5 items to buy on PLUS"*, however many were added. The default. |
| **One per item** | A separate notification for every item added. |

## How often to look while closed

| Option | How it works |
| --- | --- |
| **Live** | TidyShop keeps its connection to the family server open, so anything new arrives within seconds. Android requires an ongoing notification while it does, and it uses more battery than the other choices. It comes back on by itself after a restart. |
| **15 min** · **Hourly** · **3 hours** · **6 hours** · **Daily** | TidyShop checks for changes at about that interval. Android decides exactly when, and never checks more often than every 15 minutes. **Hourly** is the default. |
| **When opened** | Nothing runs in the background at all. You see what changed the next time you open TidyShop. |

## Quiet hours

Set a **From** and **To** time, and TidyShop stays silent in between. Turn on **Let Notify family
through** if a nudge should still reach you: somebody had to press a button for it, so it can be
worth waking up for.

## Muting one list

To silence a single busy list without touching anything else, open it and choose **Mute
notifications** from the list menu. **Unmute notifications** turns it back on.
